# SRMS - School Resource Management System
### by WeGEM (Edwin)

A comprehensive school management system built with Streamlit.

- 📚 Book Issuing & Management
- 🪑 Furniture Allocation
- 👥 Member Management
- 👨‍🏫 Teacher Management

- 📱 QR Code Generation
- 💬 Staff Chat
- 📈 Reports & Analytics
- 📝 Audit Logging
